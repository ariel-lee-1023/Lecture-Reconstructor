# 岚桥器材社：修复费用请求为什么是六百、零与四百

岚桥器材社、规则、人物、凭证和课堂事例均为合成教学材料，不对应真实法律或判决。本讲只在题设规则内分析，不把计算结果作为现实案件的赔偿标准。

三个人都违反器材使用约定，相机也都发生了实际修复费用，为什么最后分别得到600元、0元和400元？数字本身并不难算。难点在于：我们正在审查谁向谁提出的哪一项请求；违规行为与这笔费用有何关系；器材原有缺陷又怎样影响判断。先把这些问题回答完，计算才有依据。

<a id="ch-rules"></a>
## 一、把“违规了”展开成完整的请求条件

本课审查的是器材社向借用人请求修复费用。这个方向不能颠倒，费用项目也不能泛化成一切与相机有关的支出。

R1要求借用人按约定用途使用器材，并按期返还。它包含使用方式与返还时间两个方面。履行其中一项，不当然说明另一项也得到履行。同时，R1明确规定普通磨损不构成违反义务，因此不能只见器材状态发生变化，就直接认定借用人违规。

R2把修复费用请求建立在三个同时满足的条件上：第一，借用人违反R1；第二，器材发生实际修复费用；第三，该违反行为造成这项修复费用。“同时”意味着不能由其中一项替代另外两项。有违规而没有实际修复费用，不能仅凭违规计算修复费；有实际费用而没有相应因果关系，也不能把费用自动转给借用人。这是对所给规则的解释，不是在添加新的处罚规则。

证据要对应具体条件。发票可以证明其列载的收费，却不能单独证明费用由借用行为造成。因此，“这里有一张600元发票”与“这600元是某项违规行为造成的修复费用”，不是同一命题。因果判断还需要题设提供相应的原因事实，不能由金额倒推原因。

R3进一步说明一种因果条件不成立的情形：如果费用完全由器材原有隐蔽缺陷独立造成，即使借用人另有违反R1的行为，R2的因果条件仍然不满足。借用人违规，与这笔损坏费用由谁的行为造成，必须分别判断。R3不是对违规的奖励，而是在限定器材社这项特定请求的依据。

R4则处理共同原因：器材社明知缺陷却未告知，该缺陷与借用人的违规行为共同导致同一笔不可分的修复费用，此时器材社只能请求该费用的一半。这里既有器材社明知且未告知的条件，也有两种原因共同作用、费用不可分的条件。满足这些条件后，比例才是二分之一。比例来自R4的明文选择，不能因为“两边都有问题”或“这样比较公平”就自行算出一半。

## 二、甲案：按期返还为何仍需承担六百元

甲在3月1日借相机，约定用于室内拍摄，并于3月3日返还。3月2日，甲把相机拿到雨中拍照，说明书禁止淋雨；3月3日，他按期归还。检修单记录雨水进入电路是唯一损坏原因，实际修复费600元已经支付，没有原有缺陷证据，而且题设明确把检修单所载原因作为已确认事实。

教师在原课堂给出“甲付600，因为淋雨”的简短结论，写成完整分析时，需要补出三个环节。

第一，甲违反了R1的用途义务。约定为室内拍摄，实际却在雨中使用，并与禁止淋雨的说明相冲突。按期归还只能回答返还是否及时，不能消去已经发生的违规使用。这里认定的损坏也有特定原因，不能改写成R1允许的普通磨损。

第二，存在实际修复费用。题设明确给出600元修复费且已经支付，这支持R2的费用条件。

第三，甲的违规使用造成了这项修复费。桥梁在于题设已确认雨水进入电路是唯一损坏原因：甲在雨中违规使用与本次电路损坏、修复费用之间的联系，不是仅凭时间接近或一张收据推测出来的。本例接受这一因果事实，是因为题设明确作此确认，不是因为任何检修单在所有场景下都能自动确定原因。

三个条件至此分别得到事实支持。题设也没有给出原有缺陷独立致损，或器材社明知缺陷未告知并与违规共同致损的事实，不能凭空套用R3或R4。因此，按本题已经确认的事实和练习规则，器材社的修复费用请求为600元。

还有一张容易被漏看、也容易被错加的收据：甲自行购买了一条100元相机背带。没有报销约定，也没有证据说明背带是修复所需。它与器材社已经确认的600元修复费，在支出主体、项目和请求依据上都不同，不能因两张凭证都涉及相机就合计为700元。现有材料同样没有建立甲要求报销这条背带的依据。本例要排除的是把所有收据混成修复费用的算法，而不是否认600元修复费已经查明。

## 三、乙案：零元结论究竟否定了什么

乙也违反室内使用约定，把相机带到干燥室外。但是检修已经确认，电路断裂完全由交付之前的隐蔽焊接缺陷引起，户外使用对损坏没有贡献，实际修复费用为600元。

先保留相同部分：乙违反了约定用途，满足R2的第一项条件；相机发生实际修复费，第二项也存在。改变的关键事实是第三项：损坏完全来自原有隐蔽缺陷，乙的违规户外使用对该损坏没有贡献。因此，违规行为没有造成所请求的修复费用，R2的因果条件不满足，R3所说明的独立缺陷情形正好适用。器材社据这组规则对乙提出的该笔修复费请求为0元。

这个0元不等于乙履行了所有义务，也不等于任何违规都可以免责。它准确表达的是：尽管存在违规，器材社仍不能依据R2要求乙承担这笔与该违规无因果关系的修复费用。甲乙都违规、费用同为600元，结果仍然不同，正说明金额与违规标签不能代替因果判断。

原课堂中有学生反驳：既然乙违规，为了不鼓励违规，是否至少应让他承担一点？这个反驳提出的是惩罚或行为引导的理由，但当前规则要求先证明违规造成该项费用。希望防止违规，不能使一个已经确认不存在的因果贡献变成存在，也不能提供任意数额的请求依据。是否另有处罚，要看其他规则；本课并未给出，所以不能肯定或否定所有可能处罚，更不能把未给出的处罚直接塞进修复费用请求。

<a id="ch-gamma"></a>
## 四、丙案：为什么减半，而不是全部免除

丙在雨中违规使用相机，器材社明知密封圈已经裂开，却没有告知。题设进一步确认：雨水与裂纹共同造成一笔不可分的800元修复费，单独任一因素都不会造成该次损坏。

这一次，R2的三个条件都有对应事实：雨中违规使用构成违反R1；存在实际800元修复费；违规使用是与裂纹共同造成损坏的原因。不能因为另有原有缺陷，就把第三项条件抹去。因果关系可以存在于共同作用之中，题设并未要求违规行为必须是唯一原因才与费用相关。

再检查R4的专门条件：器材社明知密封圈裂开却未告知；裂纹与丙的违规行为共同致损；造成的是同一笔不可分费用。上述事实均已明确给出，所以器材社只能请求800元的一半，即400元。这个比例由R4决定，而非由我们自行衡量双方谁更值得同情。

丙为何不与乙一样全免？乙案已经确认原有缺陷独立造成损坏，违规户外使用没有任何贡献；丙案恰好改变了这个条件，违规雨中使用与裂纹共同致损，单独任一因素都不足以造成这次损坏。把“原有缺陷独立致损”与“原有缺陷参与共同致损”都缩成“相机本来有问题”，就会失去决定两案差别的事实。丙案不能照搬R3的零元结论，而应适用R4的减半后果。

现在保留一个证据不足的变式。假如丙案只有800元发票，没有上述原因查明，就不能仅凭发票宣布R4适用。还需要确定是否存在违规使用、是否存在缺陷、器材社是否明知而未告知，以及缺陷与违规是否共同导致同一不可分修复费用。列出这些需要证明的事项，不等于已经证明它们；也不能反过来从证据缺口直接认定器材社一定全额胜诉或借用人一定全免。本变式可以确定的是，发票不足以完成现有因果与R4条件的判断。

按本课教师的考试提示，答案先列R2三项要件，再逐项绑定已知事实，最后检查R3或R4的相关情形。对乙要明确指出缺少因果条件，对丙要说明共同原因为什么排除了直接照搬乙案全免的可能，并写出减半的规则依据。甲600元、乙0元、丙400元，是三组特定题设的结果，不是现实案件的一般赔偿标准。

这三案共同展示了同一种写作方法：先固定请求，再把事实送入相应条件，随后检查特殊规则与证据限制，最后才计算金额。只把“违规”“有发票”“相机有缺陷”写进答案，还没有完成论证；必须说出这些事实各自支持什么，又不能支持什么。
