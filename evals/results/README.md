# 合成执行证据

此目录仅收录本项目合成材料的实际执行产物；不包含用户真实课堂、教材全文或私人运行。baseline 是普通直接改写对照，skill 是独立上下文调用本包生成，edges 是主编排者执行的边界请求，resume 是实际章节断点及新上下文恢复，isolated 是完整包白名单隔离生成。

每组 execution 或 review 文件明确记录已知配置、独立性和限制。公开副本将临时绝对路径替换为组内相对路径或隔离目录标记；完整原始记录保留在本机 .work 中。文件内容哈希保留；路径脱敏后的元数据文件自身不宣称与原件同哈希。

匿名比较只评价此次输出的遗漏、错误、推理、例子与连贯，不证明学习效果。断点三章用于恢复协议测试，不代表超大上下文压力测试。机械夹具见 tests，不混同模型生成。
