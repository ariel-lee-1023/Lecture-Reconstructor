## Historical English reading copies and original evidence

The files from the November 15 build, including its runtime ZIP, are English translations of the historical artifacts. They were not regenerated by the model. Original bytes remain at [commit b0390af](https://github.com/ariel-lee-1023/Lecture-Reconstructor/tree/b0390af4a584b884a62dba6aba7994514df81c8d/evals/results). The [translation manifest](../../fidelity-ledger/english-translation-manifest.json) records original and current hashes, source URLs, and ZIP member identities. Each JSON record also identifies its original version.

Historical statuses, timestamps, input hashes, runtime hashes, output hashes, and standalone `.sha256` files still describe the original execution. They do not certify the translated files. Running `check_run.py` on these reading copies is expected to detect changed inputs/runtime and stale review hashes; exit code `2` is expected. Do not refresh those hashes to restore an old pass. Original source text and translated text retain line counts and stable anchors, but byte hashes necessarily differ. Explicit requests for Chinese and the 100-Chinese-character constraint are historical test conditions, not current default-language rules. ASR misspellings have English counterparts that preserve their deliberate errors and unresolved sent/received distinction.

This directory contains only actual execution artifacts using this project's synthetic materials; it contains no real user classes, full textbooks, or private runs. baseline is the ordinary direct-rewriting comparison; skill was generated by invoking this package in an independent context; edges contains boundary requests executed by the main orchestrator; resume contains actual chapter checkpoints and fresh-context resumptions; isolated contains generation using the complete package under a reading allowlist.

Each group's execution or review files explicitly record known configuration, independence, and limitations. Public copies replace temporary absolute paths with group-relative paths or an isolated-directory marker. Complete original records remain locally in .work. File-content hashes are retained; metadata files with sanitized paths do not claim the same hashes as their originals.

The anonymous comparison evaluates only these outputs' omissions, errors, reasoning, examples, and coherence; it does not establish learning outcomes. The three-chapter checkpoint tests the recovery protocol, not extreme context limits. Mechanical fixtures are in tests and are not model generation.
