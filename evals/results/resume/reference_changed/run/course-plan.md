## ch-2（assembled）

学习对象：区分到达与发出、撤销与协商、暂停与届满，确定庚关系状态。

关系：撤销以期限内到达为条件；单方撤销消灭预约但不取消成员许可；封闭只暂停且恢复不延长原时段。
