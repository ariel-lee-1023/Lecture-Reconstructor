<a id="ch-1"></a>
# 第一章　可以进入，为什么还不等于有人必须提供座位？

<a id="ch1-scope"></a>
本课讨论一个学习社怎样把进入、预约、撤销、积分与复核连接起来。以下规则、人物、数据都来自一份合成教学材料，属于教学假设，不是现行法律，也不是真实课堂或真实案件的记录。我们只在这套练习规则的范围内推理。没有前后课资料，因此理解本课所需的关系，要在这里说明。

<a id="ch1-whole-task"></a>
先把最终需要处理的事情摆在面前。庚是学习社成员，周一预约了周三10点至12点的座位，并收到成功确认。此后，他又尝试取消，周三场地发生封闭，最后还涉及退还积分。这个经历把几个问题连在了一起：庚起初取得了什么？这项关系后来有没有改变？哪些后果由哪些条件触发？如果对处理结果有异议，应怎样复核？

我们先从起点讲起。如果连“可以进入”和“可以要求谁提供什么”都没有分清，后面的撤销、费用与复核就会失去分析对象。第一章的任务是确定关系如何成立；后续发生什么，将在具备相关规则和事实后继续判断。

<a id="ch1-permission"></a>
## 一、进入许可的作用，要对准进入行为

练习规则L1先规定：注册成员享有进入公共阅览区的许可，但许可不保证座位。这两句话一起限定了许可的内容。

注册成员可以进入，意味着在本规则下，成员的进入行为不受到禁止。这里回答的是“成员可不可以进入”。它没有同时回答“是否一定有空座位”，也没有指定某个他人必须为了成员的进入而完成某种给付。把进入许可写成座位保证，就把许可的作用对象从进入行为悄悄换成了座位供给。

<a id="ch1-student-objection"></a>
合成材料安排了一个学生反问：“许可完全没用吗？”这个反问值得保留，因为只说“许可不保证座位”，容易让人误以为许可没有任何作用。它确实有作用：它排除了本规则下对进入行为的禁止。问题在于，这种作用还不足以保证另一个结果——一定有座位可用。能够进入和能够获得座位是两个不同的问题；说明前一个条件不保证后一个结果，并没有否认前一个条件本身的意义。

因此，分析时不要急着把概念分成“有用”与“没用”。先说清它改变了谁、对什么行为、处于什么位置。L1中的进入许可改变的是注册成员对进入行为的位置；座位是否有保障，还要看另一个条件。

<a id="ch1-confirmation"></a>
## 二、成功确认，才是座位义务成立的条件

L1接着规定：预约系统发出成功确认后，管理人才对该预约人负有在确认时段提供标准座位的义务。这里已经指明了关系两端：一端是得到成功确认的预约人，另一端是管理人；义务的内容是在确认时段提供标准座位。

相应地，说预约人可以要求管理人提供座位，不是从“他可以进入”推出来的，而是依据L1中这一项独立规定。它要求一个特定事实成立：系统已经发出成功确认。点击申请、看到排队提示，或者收到“已接收”消息，都不等于满足这个条件。申请进入处理过程和预约获得成功确认，不能混用。

这也说明为什么必须保留消息的具体性质。若材料只写“收到消息”，就不能擅自把它解释为成功确认；若材料明确写了成功确认，则应承认这个条件已经满足。关系判断取决于规则要求的事实，而不只取决于当事人主观上觉得预约已经办好。

<a id="ch1-jia"></a>
## 三、甲与丁：座位同样满了，依据却不同

先看甲。甲只是注册成员，看到座位坐满了，就要求乙让座。甲的注册使他取得进入公共阅览区的许可；但在给定的L1中，没有一条规则把甲的注册身份转化成乙的让位义务。因此，不能仅凭甲是成员，就推出乙必须让出自己的座位。

这个判断的范围需要说准：我们是在指出甲目前给出的依据不足以推出乙让位，而不是凭空断言一切情形下任何人都绝不可能负有让位义务。本课只给出了这些规则，不能替甲补造另一项义务依据。

<a id="ch1-ding"></a>
再看丁。丁已经收到成功确认，到场时座位也满了。这一次，除了进入许可，还存在L1规定的预约关系。管理人不能只用“大家都可以进入”来否认自己在确认时段向丁提供标准座位的义务，因为进入许可没有取代成功确认所产生的义务。

甲与丁面前都出现了“座位满了”这个事实，但决定分析结果的条件不同：甲只有注册，丁还有成功确认；同时，甲提出的是让乙让位，丁对应的是管理人的座位义务。两案并不是只替换了人名的同一道题。应当分别指出义务是否有依据，以及义务相对人是谁。不能把管理人的义务再自动转移给正在使用座位的乙。

这两层关系可以并存。一个人能够进入，和管理人必须向这个人提供确认时段内的标准座位，并不相互排斥。前者不会自动产生后者；后者也不会因为前者同样存在而消失。

<a id="ch1-cable"></a>
## 四、借充电线：不能靠相似用语扩大规则

材料还安排了一个边缘例子。工作人员说“可以借线”，却没有承诺优先权，也没有承诺对某个人负有交付充电线的义务。不能一听到“可以借”，就补上“工作人员必须立即交给我”或“我享有优先取得”的结论。

这个例子与座位问题相连的地方，是许可性表述不自动等于他人的给付义务。它的边界同样重要：L1关于成功确认后提供标准座位的规定，只说明座位关系。不能因为两件事都发生在学习社，就把借线许可改写成座位预约成功确认，也不能把座位规则直接移植成充电线交付规则。比较帮助我们检查推论，但比较本身不会创设材料没有给出的规则。

<a id="ch1-geng"></a>
## 五、回到庚：现在可以确定什么？

回到开头的庚。他是成员，因此在L1下具有进入公共阅览区的许可。他还在周一为周三10点至12点的预约收到成功确认，这又满足了预约关系成立的条件。依据L1，管理人由此对庚负有在该确认时段提供标准座位的义务。

到这里，我们已经找到了后续分析的起点，却还不能把这个起点直接写成最终结果。关系成立之后，是否发生有效撤销，是否在某个时段暂停，以及何时届满，都需要对应的规则和事实。第一章尚未展开这些规则，所以此时准确的结论是“预约关系已经成立”，不能提前断言庚最终一定能够坐到12点。

接下来要分析的，正是一个已经成立的关系怎样变动。继续分析时，要带着本章已经区分的两个对象：成员的进入许可，以及成功确认产生的座位请求和管理人的对应义务。只有把对象分清，才能判断后来某项行为究竟改变了哪一层关系。

<a id="ch-2"></a>
# 第二章　预约成立以后：撤销、暂停和届满各改变什么？

第一章确定了庚的预约关系已经成立。现在要沿着时间继续看：当预约人提出取消，或者场地出现安全问题时，原来的座位请求和提供座位义务是否仍然存在？答案取决于发生了什么、是否满足规则条件，以及规则给这种事件安排了什么效果。以下仍只使用本课的合成练习规则。

<a id="ch2-withdrawal"></a>
## 一、单方撤销以到达为准，超期协商另有条件

L2允许预约人在预约开始前一日18点前单方撤销。原句中的“18点前”如何处理18点整，由本练习附则明确：包括18:00整。因此本课统一使用“不晚于18:00”，不能把这个边界解释为必须早于18:00，也不能将它推广成现实法律的一般解释。

这里有两个必须连接起来的条件。第一，撤销通知要在规定期限以内；第二，L2规定撤销在通知到达系统时生效。我们据此比较的是到达时刻与期限，不能只看预约人何时点击发送。发出说明通知离开了发送端，到达说明系统已经收到；两者可能相隔几分钟，而这几分钟就可能改变单方撤销的结果。

“单方”表示在满足上述条件时，不必另取得管理人的同意，就能发生L2规定的撤销效果。超过期限则不能再沿用这条路线，材料另给出协商的可能，但协商须双方同意。预约人发出协商请求，只表明他希望改变关系；还不能把另一方的同意补写进事实。因此，单方撤销失败不等于双方绝不可能另行协商，也不等于已经协商成功。应分别检查两条路线各自的条件。

<a id="ch2-arrival-comparison"></a>
## 二、戊与己：几分钟为何足以改变结论？

戊在17:50发出通知，系统在18:05收到。虽然发送早于18:00，到达却晚于18:00；L2把生效所需事件规定为到达，所以这次通知不能依单方撤销规则消灭预约。若只摘取17:50，就把规则要求的事实换成了另一个事实。

己的通知则在18:00到达。按照本练习附则，18:00整仍在期限内，因此及时生效。两案的其他条件相同，比较的关键是通知到达时刻：戊在期限之后到达，己正好在期限边界到达。规则中有无包含边界的附则也必须保留；少了这一前提，不能直接移用本课结论。

<a id="ch2-withdrawal-scope"></a>
撤销生效后，消灭的是该预约产生的座位请求和管理人的对应义务。它没有取消成员身份，也没有取消L1下成员进入公共阅览区的许可。这一点回接第一章的两层关系：一个成员即使不再享有某次预约的座位请求，也不因此失去成员进入许可。分析法律效果时，必须说出变动的是哪一项关系，不能只说“权利都没了”。

<a id="ch2-suspension"></a>
## 三、安全封闭造成暂停，不自动造成撤销

L3处理的是另一种事件：存在即时安全险情，使场地必须封闭。这两个相连的条件出现时，管理员可以暂停提供座位的义务，并应退还实际受影响时段的预约积分。材料没有把一般不方便、座位紧张或者预约人未到场都规定为这种安全封闭。

暂停与撤销的效果不同。撤销消灭该预约的座位请求和对应义务；L3的封闭则没有自动撤销预约。在原确认时段以内恢复安全后，剩余时段继续有效。因此，封闭前后的分析对象仍是原预约，只是封闭实际影响的时段不能照常提供座位。

恢复也不等于重新开始计时。原来确认的结束时间保持不变。若原预约到12点，11点恢复安全，剩余时段是11点至12点，而不是从11点起重新获得原来全部时长。这是“暂停”与“延长预约”的区别；L3给出了前者，没有给出后者。

<a id="ch2-xin"></a>
## 四、辛的完整时段：恢复之后还有多久？

辛预约10点至12点。场地因安全问题在10点至11点封闭，11点开放。10点至11点是预约内受封闭影响的一小时，提供座位义务在该段暂停，并应退回该小时的预约积分。11点至12点仍属于原确认时段，安全恢复后继续有效，辛可以使用这一小时。

到了12点，预约按原确认时间届满。届满是原定时段走到了终点；它既不同于通过及时撤销而消灭预约，也不同于在预约时段中因安全封闭而暂停。把三者区分开，就能解释为何11点恢复后有一小时可用，又为何12点不能继续要求按原预约提供座位。

再改变一个事实：辛到11:30才来。场地11点已经开放，原结束时间仍为12点，所以到场后还剩半小时，不能把11点至11:30的个人迟到时长接在12点之后，让预约顺延到12:30。改变到场时刻，没有改变L3对原结束时间的限制。

<a id="ch2-lateness-objection"></a>
合成材料中有学生提出，只要没有坐满两小时，就应退还全部积分。这个反驳把“实际在座时间”当成了退款标准。L3采用的标准却是“受安全封闭影响的时段”。辛因10点至11点封闭而无法使用座位，与他自己到11:30才来，是两种原因。前者触发本条退款，后者不能仅凭“没有坐在座位上”就计入安全封闭。于是，不能从辛实际只坐了半小时，推出两小时积分全部应退；也不能把个人迟到的半小时加进封闭退款时长。这里的结论限于L3，没有另行补造关于迟到的其他退分规则。

<a id="ch2-geng"></a>
## 五、庚的关系在周二、周三分别怎样变化？

现在带着这些区别回到庚。其周三10点至12点预约已经成功确认；按L2，单方撤销通知须在周二不晚于18:00到达系统。庚在周二17:58发出取消请求，系统却在18:02才收到。17:58是发出时间，18:02才是本条所需的到达时间。由于到达超期，不能据此认定单方撤销生效。

另一路线是双方协商，但现有事实没有管理人同意协商的证据。不能用庚已经发送取消请求替代双方同意。因此，依给定事实，预约没有因这次取消请求而消灭，后续仍以周三10点至12点的有效预约为分析起点。

周三10点至11点场地因安全问题封闭，11点恢复。依L3，10点至11点提供座位义务暂停，该段属于应退积分的受影响时段；11点至12点继续有效，到12点按原时段届满。安全封闭没有把预约全部撤销，也没有把结束时间推到13点。

到此，我们已经确定了后果计算所需的关系和时段。下一章再用计价规则算出应退多少，并独立判断复核是否及时。先确定有效预约，再找与封闭重叠的部分，能够避免把一张计算正确、前提却错误的算式当成正确答案。

<a id="ch-3"></a>
# 第三章　退多少积分，能否及时复核？

前两章已经回答了关系如何成立、何时变动。现在要把这些判断用于后果计算，再看发生争议时的复核。顺序有理由：若预约已经有效撤销，就不能仍然把它当成有效预约计算封闭退款；若已经算出应退数额，也还要另查复核是否在期限内到达。实体后果与程序条件相连，却不能相互替代。

<a id="ch3-calculation"></a>
## 一、先找重叠时段，再使用计价规则

L4规定，预约每小时10积分，半小时按5积分计。本次教学只处理整半小时，其他时间粒度没有规定。面对十五分钟等材料未覆盖的时长，不能自行决定按比例、取整或者收取最低半小时；本课给定案例不需要这些补充规则。

结合L3，退款所对应的是安全封闭与有效预约重叠的时段。应当先把预约和封闭各自的起止时间摆出来，找出同一时间内既有有效预约、又因安全封闭而受影响的部分。封闭发生在预约开始之前的时间，没有侵入该预约的有效时段，不能计入这项预约的退款。

在本课所给时间粒度内，可以把计算过程写成：先确定重叠时长，再按每小时10积分或每半小时5积分换算。计价规则只解决时长换成积分的问题；它不能替我们决定哪些时长应算进去。前一步判断错误，即便后一步乘法准确，结论仍然会错。

<a id="ch3-ren"></a>
## 二、壬的示范：封闭一小时，为何只退半小时？

壬预约10点至12点，场地在9:30至10:30封闭。封闭总共一小时，但前半小时9:30至10点发生在壬的预约开始之前；只有10点至10:30同时处于有效预约和安全封闭之中。因此，实际受影响时长为半小时，按L4应退5积分。

若按封闭总时长一小时计算，就会得出退10积分。错误不在“一小时乘以10”等于多少，而在把预约外的9:30至10点也算成了壬的预约损失。两种算法使用相同的价格，差别出在适用条件是否满足。

10:30恢复开放以后，原预约并未因封闭而自动撤销，10:30至12点仍然有效；到12点仍按原时间届满。这个例子同时回扣第二章：先确认关系与原时段仍在，才谈受影响部分；退还半小时积分，也不意味着剩余一个半小时失去效力。

<a id="ch3-review"></a>
## 三、L5复核：到达及时与实体判断正确分别审查

L5规定，对退分有争议的成员应在得知处理结果后七日内申请复核。期限从得知的次日开始计算，第七日结束前到达系统即为及时。这里至少需要两个时间事实：何时得知处理结果，以及申请何时到达系统。单凭申请人已经点击发送，不能替代到达这一要求。

复核机构要检查规则适用与时间事实。管理员先前作出过处理，并不能证明处理当然正确；复核需要重新看确认、撤销、封闭、计价以及有关时刻是否支持该结果。同样，一份申请在期限内到达，只说明程序上的及时性得到满足，不能因此断言申请人的所有实体主张都成立。申请人主张退多少，仍需按L1至L4及相应事实逐步判断。

材料也没有规定提出复核申请就自动暂停其他决定。因而不能把“已经申请复核”改写为“其他决定已经停止执行”。本课能说明的是L5明文给出的复核与及时性条件，不能从程序的存在补出未规定的暂停效果。

<a id="ch3-gui"></a>
## 四、癸的期限：得知当天不计入第一日

癸在周四得知处理结果。依L5，从次日开始：周五为第一日，周六第二日，周日第三日，下周一第四日，下周二第五日，下周三第六日，下周四第七日。通知在下周四结束前到达系统，便落在第七日以内；材料给出的“下周四当天到达”因此及时。

这套算法来自本练习明文。材料按日计算，未另设工作日算法；这里列出周六、周日，是依题中连续七日进行演算，不是在宣布各法域的期限规则。如果只知道通知在下周四到达，却不知道何时得知结果，就不能算出第一日与第七日，也不能凭想象判定期限已届满或申请及时。缺失的起算事实须明确保留。

## 五、庚的完整分析：扣20、退5错在哪里？

现在把庚从周一到下周三的经历连起来。

首先看关系成立。庚是成员，周一收到周三10点至12点预约的成功确认。成员身份提供进入许可；成功确认另使管理人对庚负有确认时段内提供标准座位的义务。两小时预约依L4计20积分，系统扣20与该时段的计价相符；这还不是最终应保留多少积分的答案。

其次看关系变动。周二17:58只是取消请求的发出时刻，系统18:02才收到，晚于前一日18:00的边界。单方撤销不生效；又没有管理人同意协商的证据，因此不能认定双方已经合意消灭预约。周三仍须以10点至12点的有效预约继续分析。

再次看安全封闭的后果。场地周三10点至11点封闭，11点恢复。封闭与有效预约重叠整整一小时，依L3应退该小时积分，依L4数额为10积分。11点至12点继续有效，不因前一小时封闭而自动撤销，也不延长结束时间。由此，20积分预约扣款中应退10，按给定规则计算最后保留10积分。系统只退了5，少退了5，退分处理不符合这一次重叠时长及计价规则；纠正方向是再退5，使总退额达到10。这个结论来自确认、撤销、封闭与计价的共同适用，不仅是一道“20减5”的算术题。

最后独立看复核。庚周四得知处理结果，下周三提出复核且当日到达。按前面的逐日算法，下周三是第六日，在第七日结束以前，因此该申请及时；庚又是对退分有争议的成员，符合本课L5给出的申请情形。实体上少退5积分与程序上申请及时，都有各自的规则与事实依据。不能倒过来说，因为申请及时所以所有退分要求都应支持；也不能因为已经发现实体错误，就省略期限核对。

这里没有将庚的到达时刻改成发出时刻，没有把封闭一小时写成撤销两小时，也没有假设复核申请自动暂停了其他决定。各环节保留各自条件，才形成一条完整的分析。

## 六、只改到达时刻：哪些结论须随之改变？

保留庚的其他事实，只把撤销通知到达时刻改成周二17:59。此时到达没有超过18:00，单方撤销依L2及时生效，该预约的座位请求和对应义务已经消灭；成员身份与进入许可仍不因此消失。

这个变化直接改变后续计算的前提。原案之所以能用10点至11点的重叠时长退分，是因为当时存在周三10点至12点的有效预约；变式中预约已经撤销，就不能再把它当作有效预约与周三封闭求重叠，机械照搬“应退10积分”。

但这一点也不能推出“应退0”，或者“及时撤销所以必定全退20”。L2规定了及时撤销的关系效果，没有规定及时撤销后的积分结算方法；L3规定的是有效预约受安全封闭影响的退分，不是撤销结算规则。因此，变式能确定的是预约已经消灭，不能确定最终结算积分。要得到唯一金额，必须补充及时撤销的结算规则。在现有材料范围内，保留这项缺口，就是推理应当停止的位置。不能用看起来公平、方便或者熟悉的答案填补一个没有给出的前提。

<a id="ch3-exam"></a>
## 七、怎样组织案例答案，为什么不必每题都写四段？

合成材料中教师给出的考试提示是：完整案例可按“关系成立—变动—后果—复核”展开。庚案已经示范了这种顺序如何工作：先确认谁对谁负有什么义务，再检查撤销或暂停，随后计算相应积分，最后检查复核。每一段都向下一段提供必要前提，因而能帮助发现漏项。

教师同时说明，概念比较题不必机械写这四段。若题目只要求比较暂停与撤销，应围绕二者的触发条件、影响的关系和恢复后的效果来解释；无需硬编积分事实或复核日期。答题结构要服务于题目需要说明的关系。此处保留的是合成课程教师的安排，他要求解释为什么条件影响结果，没有承诺任何现实考试按此评分。

## 八、回到全课的问题：把四组区别连起来

庚的经历把本课开头的整体问题具体化了。进入许可让我们知道成员可以进入；成功确认使预约人与管理人之间有了特定时段的座位请求和对应义务；L2与L3说明这种关系如何消灭或暂停；L4把被规则选出的受影响时段换成积分；L5再提供对处理结果进行复核的程序。

沿这条线回看，四组区别各自阻止了一种具体错误。第一，发出与到达不同，所以17:58发出不能掩盖18:02到达已经超期。第二，暂停与消灭不同，所以安全封闭一小时以后，剩余一小时仍然有效。第三，实际在座时间与受影响时段不同，所以个人迟到不自动扩大安全封闭退款，预约开始前的封闭也不计入。第四，程序及时与实体正确不同，所以第六日申请到达还须结合实际规则审查少退积分，而不能自动认可任何金额。

这些区别没有给我们一个脱离条件的固定答案。原案应总退10积分；改成17:59到达后，及时撤销的结算反而因规则缺失而不能确定。能说明结论何时成立、何时需要修改、何时应承认现有材料不足，才完成了对这个练习制度的分析。所有推论限于已给出的合成规则；本文已经在需要处展开理由，不借“前课已经证明”代替说明。
